# Sons réels (optionnel)

Par défaut, tous les sons sont synthétisés par le navigateur (aucun fichier requis).
Pour remplacer un son par un fichier libre de droits, déposez-le ici et déclarez-le dans `manifest.json` :

    { "sfx": { "explosion": "boom.ogg", "harpoon": "harpoon.ogg" },
      "music": { "0": "calme.ogg", "1": "tension.ogg", "2": "combat.ogg", "3": "furie.ogg" } }

Noms de sons disponibles : `AvAudio.names()` dans la console du navigateur.
Banques libres conseillées : Freesound (filtre CC0), Kenney.nl, OpenGameArt, Pixabay.
Vérifiez la licence de chaque fichier.
